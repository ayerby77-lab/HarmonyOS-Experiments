## 2. 接口与导航约定

- 存储层：`AnatomyStore.open(context)` 打开数据库并建表（幂等），提供
  `listFavorites / isFavorite / addFavorite / removeFavorite / toggleFavorite`、
  `addHistory / listHistory / clearHistory`、
  `listNotes / saveNote / deleteNote`。
- 导航参数（`AnatomyRouteParams`）：键名为 `locateId`、`locateName`、`locateSystemId`。
  - 收藏/历史项点击「定位模型」→ `router.pushUrl({ url: 'pages/AnatomyBrowser', params })`。
  - 该目标是**人体浏览模块**的约定：`pages/AnatomyBrowser` 需读取上述参数，在模型就绪后调用
    Web 侧 `selectPart(id)` 完成定位并高亮；模型尚未就绪时应缓存该待定位请求。
  - 结构详情页复用同一组键读取所展示结构。
- 边界约定：`addFavorite` 对已存在结构返回 `false`（重复收藏受控）；`addHistory` 同一结构仅保留最新一次，
  超过 `HISTORY_LIMIT = 200` 时淘汰最旧记录；`saveNote` 拒绝空正文与无结构关联的写入。
