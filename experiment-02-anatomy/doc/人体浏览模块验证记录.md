## 2. 实现说明

### 2.1 本地资源导入
- 将 human-atlas 的 Vite 构建产物整体复制进 `rawfile/human-atlas/`。`index.html` 内为
  `<script type="module" crossorigin src="./assets/index-*.js">` 与同目录 CSS，`body` 仅一个 `#root`。
- 数据入口 `models/atlas.json`（version `BodyParts3D 4.0`）：`parts`（2234 项，含 `id/name/system/chunk`）、
  `chunks`（15 个分块，URL 为**根路径** `/models/body-N.bin`，并提供 `gzip` 字段 `/models/body-N.bin.gz`）、
  `concepts`（3432 项）。运行时优先取 `.gz` 并用 `DecompressionStream` 解压。
- `ATTRIBUTION.md` 随产物保留在 rawfile 中。

### 2.2 ArkWeb 离线加载
- 入口：`Web({ src: $rawfile('human-atlas/index.html'), controller })`。
- 配置：`javaScriptAccess(true)`、`domStorageAccess(true)`、`fileAccess(true)`、`cacheMode(CacheMode.None)`。
- 全过程不访问网络；模型分块从 rawfile 读取，因此**断网可用**。

### 2.3 资源请求拦截（`onInterceptRequest`）
- `mapRawfilePath(url)` 把请求 URL 归一化为 rawfile 相对路径（`bridge/AtlasResources.ts`）：
  - `resource://rawfile/human-atlas/...`（相对路径已解析）→ 原样；
  - 根路径分块 `resource://rawfile/models/body-N.bin(.gz)` → 补 `human-atlas/` 前缀重映射；
  - 支持 `http(s)/file` scheme 取 path、去除 query/hash、归一 `./`、拒绝 `..` 目录穿越。
- `mimeOfPath` 按扩展名返回 MIME（html/js/css/json/svg/gz/octet-stream）。
- 命中时构造 200 响应：`setResponseData($rawfile(path))`，并加
  `Content-Type`、`Access-Control-Allow-Origin: *`（供 Web 侧 `fetch()` 离线读取）、`Cache-Control: no-store`。
- 未命中返回 404 响应对象（回调返回类型非空，故始终返回 `WebResourceResponse`）。

### 2.4 JSBridge（双向）
- **Web → 原生**：`javaScriptProxy({ object: session.getBridge(), name: 'NativeBridge', methodList: [...] })`，
  `methodList` 固定 5 项：`onWebReady`、`onBridgeReady`、`onWebError`、`onProgressChange`、`onStructureSelected`。
  `AnatomyBridge` 通过 `setOnReady/setOnBridgeReady/setOnProgress/setOnSelect/setOnError` 注册回调，
  回调默认空实现、`close()` 可断开（契约 §6.6）。
- **原生 → Web**：`window.__atlasBridge`（由 Web bundle 注册）提供 `search/selectPart/isolate/reset/setExplode/toggleSystem/listSystems`。
  原生以 `runJavaScript(atlasCall(...))` 下发指令，表达式统一带 `window.__atlasBridge` 存在性判断，
  未就绪时返回 `false` 而不抛错；结果用 `JSON.stringify(!!...)` 回传，原生比对 `'true'`。

### 2.5 交互能力
| 能力 | 实现 |
| --- | --- |
| 旋转 / 缩放 | 由 Web 侧 Three.js 提供，原生不拦截指针事件 |
| 结构点选 | Web 点选 → `NativeBridge.onStructureSelected(id, name, systemId)` → 原生选中提示条 + 详情入口 |
| 系统切换 | 原生「系统」面板 → `toggleSystem(id, visible)`；`integumentary` 默认隐藏 |
| 隔离 | `isolate()` 只保留当前选中结构 |
| 搜索定位高亮 | 原生搜索栏 → `search(q)`；中文别名（26 组）转英文关键词，命中后 Web 侧定位并高亮 |
| 分解 / 复位 | `setExplode(v)`（0–1 步进 0.25）、`reset()` 恢复默认系统与视角 |
| 加载状态回传 | Web `onProgressChange(n)` → 会话层 → 覆盖层进度条；`onWebError` → 错误覆盖层（含重试） |

### 2.6 统一结构选中事件与按 ID 定位接口
- **选中事件**：`AnatomySession.onSelection(listener)`；回传结构由 `onStructureSelected` 补全
  `systemName`/`systemColor`（`systemId='concept'` 时显示「解剖概念」）。供详情、收藏、历史模块订阅。
- **按 ID 定位**：`AnatomySession.locate(structureId)`。
  - 就绪 → `selectPart(id)`，返回 `sent`，异步回传 `found`/`not-found`（经 `onLocateResult`）。
  - **未就绪 → 入队（去重、上限 16），返回 `queued`；`onBridgeReady` 且进度达标后一次性补发**
    （`flushPending`，不重复触发）；`onWebError` 时 `failPending` 通知 `not-found`；
    另设 25s 兜底，避免进度久未到 100 时定位被永久阻塞。
- **就绪判定**：`isReady = 已绑定 controller ∧ 非 error ∧ bridgeReady ∧ (progress≥100 ∨ 兜底)`。
- 页面入口 `applyFocusParams()`：用 `readLocateParams(AnatomyRouteParams)` 读取 `locateId`，
  同一 ID 去重（`lastFocusId`），首次进入与 `back` 返回均适用。

### 2.7 署名
- `pages/About.ets`：Human Atlas（MIT License，github.com/ashemag/human-atlas）与
  BodyParts3D 4.0（© DBCLS，CC BY 4.0，lifesciencedb.jp/bp3d）的来源、许可证与离线打包说明。
- 浏览页「关于」弹层同源摘要；rawfile 内保留 `ATTRIBUTION.md`。

### 4.2 已知限制
- **搜索词表**：Web 侧 `search` 为 `name.includes(q)` 匹配，仅原生内置 26 组中文别名；
  非别名中文词可能无匹配（回传 `not-found` 并提示）。
- **concept 选中**：解剖概念选中时 `systemId='concept'`，原生展示为「解剖概念」，不参与系统开关。
- **单例与多实例**：`AnatomySession` 为进程单例，同一时刻仅一个浏览页实例持有 `controller`；
  从收藏/历史返回导致控制器被另一实例接管时，`onPageShow` 会重新 `bindController` + `reprobe()`
  （以 `window.__atlasBridge ? "1":"0"` 探测）恢复就绪状态。
- **兜底就绪**：桥接就绪后 25s 内进度未到 100 时按可用处理（`modelSettled`），避免定位永久排队。
