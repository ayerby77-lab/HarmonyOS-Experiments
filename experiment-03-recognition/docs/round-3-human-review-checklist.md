## 4. 进去就会踩的坑（提前知道，别当成 bug 记）

1. **相机覆盖层布局**（R3-04）：预览有画面，但下半区空白、找不到快门。真机若同样，直接记 P0 阻塞。
2. **云端记录页永远降级**：`CloudRecordRegistry.register()` 全仓无调用，`CloudRecordPort` 没有实现类。不是配置问题，是没接上。
3. **模型更新同样降级**：`ModelUpdatePort` 无实现类。
4. **响应探针在手机上可能不可用**：`Index.ets:687` 用了仅平板/2in1 可用的 API。
5. **构建必须先清缓存**：资源变更后增量构建必撞 restool `11204003`，要 `rm -rf app/entry/build app/.hvigor .hvigor` 再构建，且需关闭沙箱隔离。
6. **模拟器窗口模式在自动化环境起不来**：会卡在 `huawei-settings.cfg.lock` 重试循环。人审请从 DevEco「Device Manager」启动。
