# 音乐播放APP

HarmonyOS Stage / ArkTS / ArkUI 音乐播放器，使用系统 AVPlayer 播放本地音频，使用 RDB 保存自定义歌单。

## 本地音乐库与自定义歌单

顶部提供“播放主页”“音乐库”“我的歌单”三个入口。

1. 音乐库自动扫描 App 与 entry 模块的 `files/music` 目录；已传入模拟器的五首 MP3 会自动出现。
2. 点击“导入音乐”从系统文件选择器多选音频。App 将音频复制到自己的文件目录，供后续启动使用。支持 MP3、M4A、WAV、FLAC、AAC、OGG。
3. 使用系统 AVMetadataExtractor 读取 ID3/音频标签、时长和内嵌封面。缺失标签回退到文件名、未知歌手/专辑和默认封面。
4. 搜索框支持歌名、歌手、专辑、文件名；英文忽略大小写，空搜索展示全部歌曲。
5. 在“我的歌单”输入名称并创建，然后到音乐库点击歌曲右侧“加歌单”，选择目标歌单。
6. 打开歌单可播放单曲、播放全部或移除成员；删除歌单需确认。移除成员和删除歌单均保留原音频。

歌单名称限制1—40个字符，去除首尾空格后唯一；重复加入同一歌曲会自动合并。RDB数据库 `music_playlists.db` 保存歌单与完整歌曲引用，外键级联清理成员记录。应用正常重启和覆盖安装保留数据，卸载应用会移除其沙箱数据。

扫描范围是应用可访问的音频目录；系统文件选择器用于授权导入其他目录的音频。当前播放列表是启动播放时选定歌曲集合的快照。

## 已实现

- 播放、暂停、上一首、下一首、点击列表选曲。
- 当前时间、总时长、拖动及点击进度条跳转。
- 专辑封面、歌曲名称、歌手与专辑展示；切歌同步更新信息，封面加载失败时显示默认封面。
- 应用内播放音量 0–100%，切歌保留音量。
- 顺序播放、随机播放、单曲循环。
- 加载状态、错误提示与重试、串行播放命令、资源释放及音频打断处理。

内置曲目的歌手和专辑为演示元数据；总时长取自AVPlayer。

内置三段原创合成旋律（晨光36秒、微风40秒、夜色44秒），可直接离线试听。页面隐藏时暂停；返回后点击播放继续。

## 播放规则

| 模式 | 当前歌曲结束 | 手动下一首 |
| --- | --- | --- |
| 顺序播放 | 播放下一首，列表末尾停止 | 按列表顺序切换，末尾回到第一首 |
| 随机播放 | 随机选择另一首 | 随机选择另一首 |
| 单曲循环 | 从头播放当前曲目 | 按列表顺序切换 |

上一首始终按列表顺序切换，第一首向前切换到最后一首。初次打开只加载音频，点击播放开始试听。音量滑块调整本应用播放器的相对音量，实际响度同时受设备媒体音量影响。

## 工程结构

```text
AppScope/                         应用名称与图标
entry/src/main/ets/
  entryability/EntryAbility.ets    应用入口
  pages/Index.ets                  播放器页面
  services/PlayerService.ets       AVPlayer生命周期与操作队列
  services/LocalLibrary.ets        导入、扫描、元数据及搜索
  services/PlaylistStore.ets       RDB歌单与成员关系
  model/PlaybackPolicy.ts         播放模式与时间格式化
  model/Track.ets                  试听曲目配置

```

有本地歌曲时优先加载本地音乐；空库时保留内置试听曲目供播放器演示。

## DevEco运行

1. 打开工程目录 `/Users/avery/Documents/Codex/2026-10-08/c-j-ha/outputs/MusicApp`。
2. 在“工具 → 设备管理器”启动模拟器 `VoiceCalculator_API24`。
3. 顶部选择 `entry` 和该设备，点击绿色运行按钮。
4. 页面显示“音乐播放器”，点击“播放”试听。

本机工具为 `/Applications/DevEco-Studio.app`，SDK为HarmonyOS 26.0.0，项目最低兼容版本为5.0.0(API12)。如安装步骤要求签名，在项目结构的签名配置中使用自己的开发者配置。

命令行构建：

```bash
./scripts/build.sh
```

脚本使用 DevEco 自带工具，无第三方项目依赖。构建输出为 `entry/build/default/outputs/default/entry-default-unsigned.hap`；未配置签名时会出现签名提示。已有签名包可执行 `./scripts/run.sh /absolute/path/to/signed.hap` 安装并启动。

运行逻辑测试：

```bash
/Applications/DevEco-Studio.app/Contents/tools/node/bin/node --test tests/*.test.cjs
```

## 设备验收清单

- 点击播放后有声音且时间增长；暂停后时间停止，再播放继续。
- 连续切换上下首，确认封面、歌名、歌手、专辑、音频和时间一致；三首曲目的总时长分别为0:36、0:40、0:44。
- 播放及暂停状态分别拖动进度；恢复播放后从目标位置继续。
- 音量调到0静音，再调高；切歌后音量保持。
- 顺序模式最后一首结束后停止；随机模式避开当前曲目；单曲循环结束后重播。
- 切后台后暂停，返回后可继续播放。

模拟测试使用AVPlayer替身验证命令顺序与状态处理；音频解码、实际听感、设备布局与交互以模拟器或真机验收为准。

实现依据：[华为AVPlayer开发指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-v5/using-avplayer-for-playback-V5)。
